# AGENTS.md

Instructions for AI coding agents working in this repository. Read this before changing any files.

## Project

**Mellon** — a calm, light-mode, local-first social productivity web app.
Its loop is: **Plan → Focus → Track → Build → Share → Reflect**.

The product spec lives in `Mellon-Product-Spec-and-Build-Prompt.md` (once present).
The primary visual/product source is `sources/c.pdf`.

## Read-only rule (important)

- **`sources/` is immutable.** Never create, edit, rename, move, or delete anything under `sources/`.
- Do not modify product/spec documents. Treat them as read-only references.

## Current state

The repository starts empty; the app is scaffolded incrementally in numbered phases.
Until the Phase 1 scaffold exists, the commands below are the target contract, not yet runnable.

## Stack

- Next.js (App Router) + TypeScript
- React with feature-oriented modules
- Tailwind CSS + CSS custom properties for design tokens
- Radix UI primitives, styled to the product system
- Lucide icons (1.75px stroke, 20px default)
- Zod for boundary validation
- Vitest + Testing Library for tests

## Package manager

Use **npm** (the only package manager available; do not introduce pnpm/bun/yarn).
Node 20+ required (developed on Node 24).

## Commands

```bash
npm install          # install dependencies
npm run dev          # start the dev server (http://localhost:3000)
npm run build        # production build
npm run start        # serve the production build
npm run lint         # ESLint (next lint)
npm run typecheck    # tsc --noEmit
npm test             # Vitest (single run)
npm run test:watch   # Vitest (watch mode)
npm run verify:shell # real-browser shell check (needs `npm run build` first)
```

`npm run verify:shell` drives the locally installed Chrome over the DevTools Protocol to check
responsive layout, overflow, navigation, and dialog focus. It needs a production build and Google
Chrome; set `CHROME_PATH` if Chrome is not in the default location. It is dependency-free — do not
replace it with a browser-automation package.

Run `typecheck`, `lint`, `test`, and `build` before declaring a phase done. Report the exact
commands run and their results. Fix failures you introduced; report pre-existing failures separately.

  - Do **not** add `Co-Authored-By` trailers (no Codebuff, Claude, or any other agent).

  - Commit as the repository owner's configured identity; never alter git config.

## Working rules

- Inspect current code and conventions before editing. Preserve existing, unrelated work.
- Do not regenerate or rewrite the project wholesale.
- Commit attribution: repository owner only — no AI co-author or generator trailers (see above).
- Do not add unnecessary dependencies or a second testing toolchain.
- Work in small, reviewable increments; keep the app runnable after every change.
- Never edit anything under `sources/`.

## Honesty rules

- Build real behavior, not mock controls. Every visible control must work, navigate to a real
  screen, or be clearly disabled with a stated reason.
- Never claim configured auth, server sync, social delivery, notifications, analytics, or audio
  playback unless it is implemented and verified.
- When a service or credential is absent, ship an honest local/demo or disabled state and
  document the exact requirement. No fake loading, fake charts, or simulated external success.

## Data and privacy

- Local-first: persistence lives behind repository interfaces with a browser adapter
  (IndexedDB for structured data; localStorage only for small preferences).
- Version the schema and migrate safely.
- Private by default. Sharing is opt-in, previewed, and limited to allowlisted fields.
- Never inject sample/demo records into a real signed-in profile.

## Accessibility

- Semantic HTML, keyboard operation, visible focus, WCAG AA contrast.
- Honor `prefers-reduced-motion` (and any in-app override).
- Adequate touch targets; meaningful loading, empty, and error states.

## Copy and tone

- Concise and humane. No lorem ipsum, no shame-based streak copy, no public leaderboards,
  no childish game art, no visual clutter.
